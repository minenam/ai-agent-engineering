# KMP 화면 구현·검증 에이전트

**크루원** 우유진 · **마지막 갱신** 2026-11-20 (하네스 v0.4.14 기준)

- [에이전트 저장소](https://github.com/wooyj-1217/kmp_agent)
- [메모 데모 앱 구현 브랜치](https://github.com/wooyj-1217/kmp_agent_demo_app/tree/demo/agent-0.4.0)

Figma와 API 명세를 받아 Android, iOS, 웹에 쓸 Kotlin Multiplatform 기능을 구현하는 에이전트입니다. 승인한 요구사항별로 빌드와 테스트 결과를 남기고, 필요한 검증 결과가 빠져 있으면 완료 처리를 막습니다.

## 문제 정의와 해결 방식

AI에 화면 구현을 맡기면 빠진 디자인 요소나 인수 조건을 찾아 다시 지시하고, 수정한 결과도 직접 확인해야 합니다. 구현 전에 요구사항과 디자인을 테스트 항목까지 연결해 두면 이런 왕복을 줄일 수 있을지 확인하고 있습니다.

1. 요구사항·디자인·API 명세와 인수 조건을 정리하고 작업 범위 및 기술 계약을 승인합니다.
2. 승인된 범위에서 `data`, `domain`, `ui` 계층을 구현하고 빌드·테스트 결과를 작업 원장에 연결합니다.
3. 별도 QA 세션에서 구현 결과를 확인하고 개발자 피드백을 반영합니다. 실행 가드는 도구를 호출할 때 승인 범위를, 작업을 끝낼 때 검증 기록을 확인합니다.

## OpenAI 기술 활용

코드 수정이나 명령 실행 전에는 Codex의 `PreToolUse` 훅을 쓰고, 세션을 끝낼 때는 `Stop` 훅을 씁니다. 작업별로 독립 QA 응답과 토큰 사용량도 기록합니다. [설치와 Codex 훅 연결](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.14/docs/installation.md) · [독립 QA](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.14/docs/qa.md) · [토큰 기록](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.14/docs/token-usage.md)

## 막힌 점과 배운 점

초기에는 가드에 걸리면 작업 도중 Git push나 에이전트 업데이트도 막혔습니다. 어떤 작업을 막을지는 정해 뒀지만, 정상 작업으로 돌아가는 경로가 부족했습니다. v0.4.12에서 기존 T2 승인을 연결해 앱 구현을 재개했습니다.

웹 검증에서는 명령 시작 로그만 찍히고 테스트 프로세스가 뜨지 않았습니다. 이후 두 릴리스에서 사전 검사 단계별 소요 시간과 잠금 대기 정보를 로그에 추가했습니다. 앱에서 다시 실행해 어디서 멈추는지 확인할 예정입니다.

## 설치·실행

macOS 또는 Linux에서 Python 3.10 이상, Git, `rtk`가 필요합니다. 최초 설치는 대상 Git 저장소에 v0.4.14 태그를 지정하는 절차를 따릅니다. [최초 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.14/docs/installation.md#최초-설치)

v0.4.3~v0.4.13 설치본은 제품 저장소 루트에서 다음 명령으로 업데이트하고 상태를 확인합니다. 초기 설치나 업데이트 후에는 Codex의 `/hooks`에서 설정을 검토하고 새 세션에서 동작을 확인합니다. [버전별 업데이트 및 훅 확인](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.14/docs/installation.md)

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.14
rtk proxy python3 .kmp-agent/agent.py status
```
